# 最后的轻语 · Whisper 听写版

参考 BetterWispr 的普通听写流程，保留两个主要功能：本地语音输入，以及可选文字润色。原生 SwiftUI + AppKit，WhisperKit 1.1.1。

## 名称与图标

应用名称为“最后的轻语”，构建输出 `build/最后的轻语.app`。沿用原有应用标识、钥匙串和设置。`Assets/AppIcon.png` 根据用户参考图通过内置 imagegen 重绘，保留蓝金双叶与斜向羽箭；构建时生成 macOS ICNS。菜单栏使用原生矢量模板图，将同一轮廓简化为单色双叶和羽箭，适配明暗背景；录音时变红，处理中变淡。菜单栏预览位于 `Assets/MenuBarIcon-preview.png`。

## 使用

1. 点击目标文字框。模型会在启动时后台准备；未就绪也可先录音，停止后等待模型完成加载。
2. F5（映射为 F13）开始录音，开始提示音响起即可讲话，此时麦克风已在收音。浮动音频条显示麦克风活动。
3. 再按 F13 停止。Whisper Large v3 Turbo 识别整段录音，执行基础文字清理，然后一次性粘贴到停止时的光标位置。
4. 开启 API 润色时，识别文字先送到文字 API 进行断句、标点和口水词整理，再一次性输入最终结果。润色失败则输入本地结果。

不再执行录音期间滚动窗口解码、选中文字、退格修订或异步整段替换。处理完成前不能开始下一次录音，避免两次结果交错。录音期间可移动光标；停止后处理期间移动光标、编辑文字或切换应用，则取消自动输入，并将结果保留在剪贴板。

仅保留右上角菜单栏图标；设置、录音和退出均由菜单栏入口操作，不显示 Dock 图标。开始／结束提示音和录音柱状浮窗继续保留。

## 响应速度

开录不等待模型、钥匙串读取或目标输入框的辅助功能查询。已有麦克风权限时直接使用授权状态；应用启动时初始化音频图，停止后保留引擎对象但停止硬件收音，空闲时不持续录音。

开始／结束使用 Kenney Interface Sounds 的 CC0 现成素材 maximize_003 / minimize_003，两者均约 212 毫秒；原素材仅转为 WAV，不合成、不做音量增强。播放音量为 0.55，不改变系统音量。来源与许可见 Assets/Audio/README.md 及应用资源内 KENNEY-AUDIO-LICENSE.txt。开始音在第一个音频缓冲到达后异步播放，不阻挡音频写入，结束音在麦克风停止后播放。按键到首个音频缓冲的真实耗时显示在状态栏菜单中，停止后还显示定位、识别与 API 润色各自耗时。首次授权、设备切换和蓝牙麦克风仍可能增加启动时间。

API 配置在后台读取，关闭润色时不读取密钥；开启润色的设置在本次录音开始时加载。剪贴板的 750 毫秒恢复延迟改为后台任务，不再阻挡下次录音；快速连续输入仍保留最初剪贴板。

DeepSeek 快速预设使用 `deepseek-flash`；只有手动点击预设才改变已有模型设置。当前 API 仍等待完整整理结果后一次输入，流式返回本身不减少生成全文所需时间。

`--capture-smoke` 只在已获得麦克风权限时进行三次短暂真实收音，记录开录路径到首个缓冲的时间，删除音频，不调用 API、不执行文字粘贴；没有权限则直接报告，绝不模拟或自动确认授权。本机三次测得约 189 / 210 / 223 毫秒，音频图初始化约 162 毫秒（在应用启动时执行），结果见 `Capture-validation.json`。诊断跳过目标输入框检查，实用环境中的设备、负载、首次权限和快捷键调度还会影响延迟，不作为所有设备的保证。

## 模型

使用 BetterWispr 提供的标准模型变体 `openai_whisper-large-v3-v20240930_turbo`，约 1.64 GB，替换先前约 627 MB 的压缩模型。模型不提交至 GitHub。恢复项目后运行 `python3 Scripts/download-model.py`，将标准模型及离线分词器下载至 `Models/`；需要约 1.7 GB 空间和网络。

不再注入预设英文词汇或截断到 8 秒音频。整段解码使用自动语言检测、VAD 长音频分块、质量阈值和最多两次温度回退。中英文识别能力取决于模型和录音质量，不承诺达到具体准确率或 0.5 秒延迟。

首次加载需要 Core ML 编译，可能等待几分钟；后续使用缓存。模型不嵌入应用包，开发版从相邻 `Models/` 加载；移出开发目录后从 Application Support/VoiceInput/Models 准备模型。

## 无人声与环境噪声

停止录音后，先由随应用附带的 Silero VAD v6 本地模型判断人声，不再仅凭“音量不为零”。没有有效人声则返回空结果，既不执行 Whisper 推理，也不进入文字润色 API；状态栏显示“未检测到有效语音，未输入文字或调用 API”。检测模型缺失／失败时也不降级跳过检查。

16 kHz 音频按 512 个新样本（32 毫秒）加 64 个上下文样本处理，每次录音重新清空模型状态。要求一个人声片段内至少 128 毫秒高概率证据（≥0.6，峰值≥0.8），过滤孤立短脉冲。片段首尾分别保留 200／300 毫秒，识别前仅裁掉整个录音的前后噪声，不删除讲话之间的停顿。

本机样本检查覆盖 5 段真实 ESC-50 雨声、2 段风声、2 段键盘声、低音量雨声、静音、开始提示音、普通与低音量中英混合讲话、短句“好的”以及讲话混雨声。16 个场景全部符合预期，并从正式转写入口核对 9 段环境声直接返回空文本且没有初始化 Whisper。结果见 `VAD-validation.json`。这不是用户窗外雨声或所有环境的保证；极短或很轻的发音仍可能被过滤，人声广播也可能被当成讲话。

约 5 秒样本的本机检测耗时通常约 10 毫秒，首次模型加载约 70 毫秒。模型不足 1 MB、CPU 本地运行，无需 API。模型与适配代码许可、来源见 `SILERO-NOTICE.md`、`SILERO-LICENSE.txt` 和 `SILERO-THIRD-PARTY-NOTICES.txt`。

## 标点和口水词

- Whisper 原生生成标点。基础清理保留断句，将紧邻中文的部分英文标点转为中文形式，并为合适的中文结尾补句号。
- 删除明确独立的“嗯”“呃”、um/uh 等犹豫音，以及少量明显的代词重复。
- 不猜测任意中文句子的逗号位置，不一律删除“那个”“然后”“就是”，不全局去重，不改价格、数字、单位、URL 或代码。
- 需要语义断句和更完整清理时，手动开启 API 润色。只发送识别文字，不发送录音；按语义整理自然段、并列列表和有序步骤，短聊天不强行列表；保留中英混合、原意、数值和有意义的重复，不回答文本中的问题。纯英文润色结果出现中文、或中英混合内容中的英文全部消失时，会拒绝替换并保留本地结果；这层检查不能保证发现混合文本中每一处局部翻译。直连 DeepSeek 官方服务时显式关闭思考模式，避免为文字整理生成额外推理。

## 设置与隐私

API 润色默认关闭。本次版本使用新的开关设置，不继承旧版已启用状态；已有文字服务地址、模型与密钥继续保留。填写兼容 chat/completions 的 HTTPS 服务地址、文字模型 ID、API 密钥即可，可使用已有 DeepSeek 或 MiMo 的文字模型。旧版语音转写 API 不再参与听写。

“确认保存”显示保存结果。独立“测试 API”发送固定中英文字，显示实际响应和耗时，不开启润色、不使用麦克风，也不上传录音；会产生少量费用。

密钥在 macOS 钥匙串的通用密码条目 `local.voiceinput.api` 中，账号为 `polish-key`，用“钥匙串访问”查看。设置中的“载入已存密钥”仅在用户点击时请求钥匙串授权。其他配置在 UserDefaults。

辅助功能授权按钮只请求权限；打开系统设置是单独按钮。开发版临时签名更新可能需要重新授权。

本地识别期间无音频上传；只有模型准备可能下载公开文件。临时录音处理完成后删除，强退／崩溃可能留下临时文件。无订阅、历史记录或遥测。

跨应用输入只发送一次粘贴事件，不选中或删除文字。剪贴板等待 750 毫秒后恢复；若用户期间复制了新内容，则保留用户的新剪贴板。应用没有统一的粘贴成功回执，真实编辑器兼容性仍需实测。

## 构建与检查

私有备份仓库：`GundamDr1ver/last-whisper`。需要已授权的 GitHub 账号、macOS 15+、Apple Silicon、Python 3 和 Xcode 工具链：

```sh
git clone https://github.com/GundamDr1ver/last-whisper.git
cd last-whisper
python3 Scripts/download-model.py
./Scripts/build-app.sh
swift test
open 'build/最后的轻语.app'
```

`--whisper-smoke` 用固定 5.74 秒测试音频运行真实模型，记录整段识别和耗时，不使用麦克风、不调用付费 API、不向其他应用输入。结果见 `Whisper-validation.json`。自动测试覆盖保守文字清理、中文标点、混合文本与 URL/数值保护、文字 API 请求及错误处理、剪贴板格式恢复。真实麦克风和 Codex 输入框仍需用户验证。
